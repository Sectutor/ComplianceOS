# ComplianceOS

ComplianceOS is a comprehensive Governance, Risk, and Compliance (GRC) platform designed to streamline security frameworks (ISO 27001, SOC 2), risk management, and business continuity planning.

## Quick Start

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Setup Environment:
    ```bash
    cp .env.example .env
    # Edit .env with your credentials
    ```

3.  Run Locally:
    ```bash
    npm run dev   # Frontend
    npm run server # Backend
    ```

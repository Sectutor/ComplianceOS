Security Practices

🔒

Encryption

Data encrypted at rest via APP_ENCRYPTION_KEY (AES-256-GCM). TLS 1.3 in transit. All secrets stored as env vars, never in database.

🔑

Authentication & Access

JWT-based sessions with optional MFA. Role-based access control (admin, client admin, client editor, auditor, viewer). Session expiry and refresh. Magic link login supported.

📋

Audit Logging

Immutable audit trail for all evidence operations. Every control change, evidence upload, and status transition is logged with timestamp, user, and IP.

🖥️

Infrastructure

Self-hosted on your VPC or bare metal. No cloud dependency. Telemetry opt-out via NO_TELEMETRY=true. All outbound calls are documented and optional (except license validation).

🔍

Vulnerability Management

We dogfood our own product — GRCompliance tracks our security controls and evidence. SBOM available. Critical CVEs patched within 48 hours.

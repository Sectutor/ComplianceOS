ComplianceOS · Self-Hosted · Community Edition (AGPL)

Run your compliance OS locally in one command.

A single command downloads the stack, generates all security secrets, provisions the database, and seeds a fully populated demo workspace — so you can explore every capability immediately.

1. Prerequisites

One thing: Docker (with Docker Compose), running on your machine. Get it from docker.com — Docker Desktop for Windows and macOS, or the Docker Engine for Linux servers.

2. Run the single command

Linux & macOS — paste this into your terminal:

curl -fsSL https://raw.githubusercontent.com/Sectutor/ComplianceOS/main/install.sh | bash

Windows — paste into PowerShell:

irm https://raw.githubusercontent.com/Sectutor/ComplianceOS/main/install.ps1 | iex

The installer creates a complianceos/ folder, writes the compose file, pulls the prebuilt image from GHCR, and starts the stack. First boot takes a minute: the database schema is provisioned, security secrets are generated automatically, and the demo workspace is seeded.

3. Sign in

Open http://localhost:3002. On first boot the server generates a strong admin password for you — it is printed once in the install log and saved to the complianceos_app_data volume:

Show the generated password

docker compose -f docker-compose.selfhost.yml logs complianceos | grep "Generated admin password"

No default passwords ship with the image — not for the admin account, not for the JWT signer, not for the encryption key, and the database port is not exposed to your network.

A fully populated compliance workspace

LaTorre LTD, a demo enterprise with ISO 27001 / SOC 2 / GDPR / NIS2 frameworks, 1,200 tracked roadmap tasks, a live Action Center with 2,000+ real findings across nine categories, evidence, vendors, risks, policies and a step-by-step certification workflow — so every capability is explorable from minute one.

Stop and start again

Stop: docker compose -f docker-compose.selfhost.yml down — your data and secrets persist in volumes. Start again anytime; nothing is re-generated.

Want a clean production deployment instead of the demo workspace? Set DEMO_DISABLE_CAPABILITY_SEED=true before running the installer.

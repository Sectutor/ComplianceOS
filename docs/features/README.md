# ComplianceOS User Documentation

Welcome to the comprehensive user guide for ComplianceOS. Below you will find detailed documentation for each module and feature.

## 📚 Core Modules

### Governance & Strategy
*   [**Governance Workbench**](./governance-workbench-user-guide.md): Manage your entire GRC program from a single pane of glass.
*   [**Policy Management**](./policy-management-guide.md): Create, distribute, and track policy acceptance.
*   [**Framework Mapping**](./framework-mapping-guide.md): Map your controls to multiple standards (ISO, SOC 2, HIPAA).
*   [**SAMM v2 Assessment**](./samm-v2-user-guide.md): Assess your software security maturity.

### Risk Management
*   [**Risk Management**](./risk-management-guide.md): Maintain your enterprise Risk Register and mitigation plans.
*   [**Asset Management**](./asset-management-guide.md): Track critical assets and link them to risks.
*   [**Threat Intelligence**](./threat-intelligence-guide.md): Monitor real-time threats and vulnerabilities (NVD/CISA).
*   [**AI Governance**](./ai-governance-guide.md): Manage AI systems using the NIST AI RMF.

### Compliance Operations
*   [**Audit Hub**](./audit-hub-guide.md): Collaborate with auditors and manage evidence collection.
*   [**Vendor Management (TPRM)**](./vendor-management-guide.md): Assess and monitor third-party vendor risks.
*   [**Project Management**](./project-management-guide.md): Integrate security into project lifecycles.
*   [**Employee Onboarding**](./employee-onboarding-guide.md): Automate security training and policy sign-offs for new hires.

### Incident Response & Resilience
*   [**Incident Response**](./incident-response-guide.md): Report and manage security incidents (NIS2 compliant).
*   [**Business Continuity (BCP/DR)**](./business-continuity-guide.md): Create BIA, recovery strategies, and continuity plans.

### Privacy & Trust
*   [**Privacy & GDPR**](./privacy-compliance-guide.md): Manage ROPA, DPIAs, and DSARs.
*   [**Trust Center**](./trust-center-guide.md): Share your security profile publicly via a gated portal.

## 🛠️ Configuration & Setup
*   [**Integrations**](./integrations-guide.md): Connect email, import data, and use the API.
*   [**Knowledge Base**](./knowledge-base-guide.md): Manage internal FAQs and documentation.
